# Protótipos - FlowPulse

Os protótipos deverão ser criados no Stitch utilizando:

- `docs/prd.md`;
- `docs/spec.md`;
- `docs/design.md`.

## Telas mínimas

1. Login
2. Dashboard
3. Automações
4. Integração de automação
5. Execuções
6. Incidentes
7. Detalhe do incidente
8. Análise assistida por IA

## Fluxos que precisam ser navegáveis

### Fluxo 1

Cadastro -> credencial -> teste -> ativação.

### Fluxo 2

Execução com falha -> incidente -> assumir -> investigar -> IA -> resolver.

## Evidências a registrar

- link do projeto no Stitch;
- screenshots das telas;
- variação gerada;
- evidência do modo Prototype/Interact;
- principais ajustes feitos após avaliação.
